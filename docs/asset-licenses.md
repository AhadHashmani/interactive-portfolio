# Asset and license notes

- The map, landmarks, vehicle, badges, and interface illustrations are drawn from original Canvas and CSS shapes in this project.
- No third-party photos, screenshots, icons, game assets, or audio files are bundled.
- Web fonts are requested from Google Fonts (`DM Sans`, `Manrope`, and `DM Mono`). System sans-serif and monospace fallbacks are defined in CSS if the font service is unavailable.
- Project repositories are linked to their owners' public GitHub pages. Their assets are not copied or represented as reusable portfolio media.
